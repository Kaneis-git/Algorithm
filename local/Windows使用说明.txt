KnowledgeHub AI 0.6.0 — Windows 本机使用说明

Phase 2–6 已完成：真实搜索、SQLite 历史/收藏/缓存、可配置 AI 扩展与总结。

一、首次安装
1. 安装 Node.js 24.x Windows 版本（https://nodejs.org/en/download）。
   保留 npm 与 PATH 选项，建议使用最新 24.x 版本。
2. 将整个压缩包解压到有写入权限的目录，例如 D:\KnowledgeHub。
   不能直接在压缩包里双击脚本。
3. 双击 01-setup.cmd。等待安装与构建完成，首次安装需要联网。
   脚本会在没有 .env.local 时自动创建它，不覆盖已有配置。

二、配置搜索与 AI
1. 用记事本打开项目根目录 .env.local。
2. 填写 BOCHA_API_KEY，启用默认网页、PPT/PDF、哔哩哔哩视频索引。
3. 如需 AI，填写 AI_API_KEY；默认服务地址为 DeepSeek，模型为 deepseek-flash。
4. GITHUB_TOKEN 可选，不填时使用匿名公开仓库搜索。
5. 没有密钥仍能启动网站。未配置的功能会明确提示，不显示假搜索结果。
6. 不要把自己的密钥发在聊天、截图或提交到 GitHub。

三、启动
1. 双击 02-start.cmd，保留命令窗口。
2. 浏览器访问 http://127.0.0.1:3000 。
3. 点“配置”查看配置说明，搜索结果页显示实际来源状态。
4. 下次只需重复本节，不用重新安装。
5. 停止时在窗口按 Ctrl+C，按提示结束进程。

四、常用操作
- 输入主题搜索，分类切换不重新调用 API。
- 资源卡片点“收藏”，从顶部“收藏”入口筛选或取消收藏。
- 搜索历史在主页显示。数据保存于 data/knowledgehub.db。
- 再次搜索会使用有效缓存，点“重新搜索”可跳过缓存。
- AI 总结基于搜索标题和摘要，可点击来源核对；不是阅读全文后的结论。

五、更新与备份
- 修改 .env.local 后停止并重新启动；通常不需要重新构建。
- 修改或更新源码后重新运行 01-setup.cmd，再启动。
- 更新时保留自己的 .env.local 和 data 文件夹。
- 备份前停止应用，复制整个 data 文件夹；恢复时也先停止应用。
- 不要把数据库放进 .next 或 node_modules。

六、排障
- 找不到 Node/npm：安装 Node.js 24.x 后重新打开脚本。
- 安装失败：保留报错，检查网络与 npm 下载连接。
- 提示端口占用：关闭旧启动窗口，不要反复双击启动。
- API 超时或额度不足：检查对应服务、密钥和额度；单个来源失败不会丢弃其他结果。
- 数据保存失败：将项目放到用户可写目录，检查磁盘空间。
- PowerShell 阻止 npm.ps1：使用 npm.cmd 或随包脚本，不必全局放宽执行策略。

本网站只在自己电脑运行，默认不对局域网开放。在线搜索与 AI 仍需要网络，第三方服务可能收费。
本次验证环境为 Linux/Node.js 24；未在你的 Windows 电脑执行双击与浏览器交互验收。
更多配置、API、验证记录见 README.md 与 docs/PHASES.md。
